# 子代理目录

按需选用。本文件只说明职责与建议权限；正文请读取对应 `.md` 文件。

| 文件 | 专长 | 适用场景 | 建议权限 |
|---|---|---|---|
| `product-scout.md` | 同类产品拆解、开源方案调研 | 需求成型阶段，寻找现成方案或对标做法 | 只读 |
| `ui-architect.md` | 布局、信息层级、交互反馈、视觉一致性 | 需要界面结构与交互评审 | 可写样式与组件 |
| `reverse-engineer.md` | 逆向、协议、二进制与打包产物分析 | 需要确认现成库或黑盒组件的实际行为 | 只读，可本地执行 |
| `deep-debugger.md` | 疑难排障、日志取证、竞态复现 | 现象异常且多次修改无效 | 只读，可运行命令 |
| `security-auditor.md` | 并发竞态、越权、隐私与密钥审计 | 涉及权限、并发或敏感数据 | 只读 |
| `qa-tester.md` | 独立对抗式测试与回归验收 | 开发完成后需要独立验收 | 可写测试 |

自定义子代理放在 `custom/subagents/`：与官方同名时优先使用自定义版本，一键更新不会修改该目录。
