# 特种兵花名册

大队长按需翻牌子。**这里只给"谁擅长什么"，正文请自己读取对应 `.md`。**

| 文件 | 专长 | 什么时候叫他 | 建议权限 |
|---|---|---|---|
| `product-scout.md` | 同类产品拆解、开源轮子侦察 | 需求刚成型，要找现成方案或对标做法 | 只读 |
| `ui-architect.md` | 布局、信息层级、交互手感、视觉一致性 | 要出界面结构、挑刺"工科堆砌风" | 可写样式/组件 |
| `reverse-engineer.md` | 逆向、协议、二进制与打包产物分析 | 要搞清现成库/黑盒怎么跑的 | 只读 + 本地执行 |
| `deep-debugger.md` | 疑难排障、日志取证、竞态复现 | 现象诡异、改了几次没好 | 只读 + 运行命令 |
| `security-auditor.md` | 并发竞态、越权、隐私与密钥审计 | 涉及权限、并发、敏感数据 | 只读 |
| `qa-tester.md` | 独立对抗式测试与回归验收 | 施工完成要独立挑刺 | 可写测试 |

私有扩展放 `custom/subagents/`，同名会覆盖官方版，一键更新不会碰它。
